# Documentation

This directory contains the stable documentation for the internship demo. It
describes the finished system rather than the chronological research log.

| Document | Purpose |
|---|---|
| [method.md](method.md) | Problem definition, T2MIR baseline and DT2MIR contribution |
| [dataset.md](dataset.md) | 42/6 dynamics split, official-style collection and validation contract |
| [evaluation.md](evaluation.md) | Frozen Isaac Sim and paired MuJoCo protocols and reported results |
| [reproduction.md](reproduction.md) | Environment, training, evaluation and figure-generation entry points |
| [limitations.md](limitations.md) | Claims that are supported and explicit project boundaries |

The machine-readable numbers behind the README figures are stored under
`artifacts/results/`. Large datasets, checkpoints and generated robot assets
are deliberately excluded from source control.
